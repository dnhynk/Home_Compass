# R1. KOFR (한국무위험지표금리)

## 도달 경로 (재현 가능)

```
orca tab create --url "https://www.kofr.kr/rate/rateStatistics.jsp" --json
# WebSquare 렌더링 대기 (약 10초). 클릭·프레임 진입 불필요 — 표는 최상위 문서에 있다
orca eval --expression 'document.body.innerText' --json
```

**앞 조사가 실패한 이유:** HTTP 클라이언트로 받은 HTML 3,434바이트에는 표가 없다.
표는 WebSquare 가 JS 로 그린다. **브라우저로 열면 최상위 문서 innerText 에 그대로 나온다.**
별도 API·프레임·클릭이 필요 없었다.

# R2. 국고채 5년 — 금융투자협회 최종호가수익률

## 도달 경로 (재현 가능)

```
# ① https://www.kofiabond.or.kr/ 는 프레임셋이다. 최상위 문서 innerText 는 빈 문자열이다
orca goto --url "https://www.kofiabond.or.kr/" --json
orca eval --expression '...document.querySelectorAll("iframe,frame")...' --json
#   → frames: ["https://www.kofiabond.or.kr/#", "https://www.kofiabond.or.kr/html/MAIN.html"]

# ② 본문 프레임으로 직접 이동 (WebSquare 로 리다이렉트된다)
orca goto --url "https://www.kofiabond.or.kr/html/MAIN.html" --json
#   → 최종 URL: https://www.kofiabond.or.kr/websquare/websquare.html?w2xPath=/xml/main.xml
# 렌더링 대기 약 12초

# ③ 기본 탭은 「지수」다. 「최종호가수익률」 탭을 클릭해야 금리가 나온다
orca snapshot --json          # role=tab, name="최종호가수익률" 의 ref 확보 (이번엔 @e44)
orca click --element "@e44" --json
orca eval --expression 'document.body.innerText' --json
```

**앞 조사가 실패한 이유 — 두 겹이다.**
(1) 루트가 `<frameset>` 이라 최상위 문서에는 본문이 없다.
(2) 본문 프레임에 들어가도 **기본 탭이 「지수」**여서 금리표가 렌더링되지 않는다.

- `2026.08.13 22:04 기준` 은 **화면 갱신 시각**이다. 수익률 자체의 기준시각은 표 아래 주석이 정한다:
  **오전 = 11시30분, 오후 = 16시.**
- 따라서 `국고채권(5년) 오후 4.016` 의 기준시점은 **2026-08-13T16:00:00+09:00**,
  `오전 4.001` 은 **2026-08-13T11:30:00+09:00** 이다.

## 확인하지 않은 것

- 같은 사이트의 **「장외거래대표수익률」**(실거래 기반)에도 국고채 5년이 있으나 **열지 않았다.**
  최종호가수익률(호가 기반)과 값이 다를 수 있고, 어느 계열을 쓸지는 우리 선택이다.
- **일별 값이다.** 상수로 고정하려면 어느 시점을 쓸지(당일/월평균/분기평균)가 별도 결정이다.
  이 문서는 관측값과 기준시각만 싣는다.
