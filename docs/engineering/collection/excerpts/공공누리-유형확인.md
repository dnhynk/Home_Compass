> 문서 페이지만이 아니다.** 유형을 모르는 채로 협의 필요를 판정할 수 없다.
> `FINDINGS.md` D2·D3 과 `excerpts/R6-공공누리-AI유형.md` 4절이 이미

## 0. ★★ 먼저 — 우리가 저작물에 하는 일을 정확히 적는다

이용조건 판정·심사 답변·협의 문안 어디에도 **「학습」이라고 쓰지 않는다.** 사실이 아니다.

| | 사실 |
|---|---|
| 우리가 하는 것 | **원문 텍스트를 LLM 에 입력해 판정 규칙으로 구조화 추출**한다. 출력은 `RuleDraft` 이고 인용 구간(span)이 원문에 실재하는지 기계가 대조한다 |
| 우리가 하지 않는 것 | **모델 학습·가중치 갱신을 하지 않는다.** 학습용 데이터셋을 만들지도, 재판매하지도 않는다 |

**따라서 공공누리 AI유형의 적용 대상이 아니다.** `excerpts/R6-공공누리-AI유형.md` 가 옮긴 원문:

> 이용자는 AI유형이 표시된 공공저작물을 '인공지능 학습용 데이터'로 이용할 목적이 아닌 경우
> 함께 표시된 기존 공공누리 유형의 이용조건을 준수하여야 합니다.

→ 우리는 **기존 유형(제1~4유형)의 이용조건으로 판정받는다.** 이 실사가 확인한 것이 그 유형이다.

서울시 저작권 정책도 같은 취지를 자기 문장으로 적어 두었다 (2026-08-14 원문확인):

> AI유형이 표시된 공공저작물은 '인공지능 학습용 데이터'로 이용하는 목적에 한하여 출처를
> 생략할 수 있으며, 다른 목적으로 이용하는 경우 함께 표시된 공공누리 유형의
> 이용조건(출처명시 포함)을 반드시 준수하여야 합니다.

## 2. ★ 서울시 2건 (⑥⑧) — 제4유형. 표면은 `seoul.go.kr` 고시·공고였다

### 2.1 앞 과업이 본 표면과 못 본 표면

| 표면 | 앞 과업 | 이번 |
|---|---|---|
| 서울주거포털 게시글 (`housing.seoul.go.kr`) | 봤다 — 마크 없음 | 같음 (아래 2.4) |
| 첨부 PDF 내부 | 봤다 — 마크 없음 | 확인하지 않음(재확인 불요) |
| **서울시 홈페이지 고시·공고 (`www.seoul.go.kr`)** | **보지 않았다** | **여기에 유형이 있다** |

### 2.2 도달 경로 (재현 가능)

```
orca goto --url "https://www.seoul.go.kr/news/news_notice.do" --json      # 서울소식>공고>고시·공고
# 검색 폼은 hash 네비게이션이라 URL 로 바로 가지지 않는다. DOM 으로 넣고 누른다:
orca eval --expression 'var f=document.getElementById("searchForm"); f.srchText.value="청년월세지원"; f.querySelector("[name=btnSearch]").click()' --json
# 검색 후에는 쿼리스트링이 붙으므로 그 다음부터는 URL 로 직행할 수 있다
orca eval --expression 'fnTbbsView("457234")' --json      # ⑥ 상세
```

| | ⑥ 청년월세지원 | ⑧ 임차보증금 이자지원 |
|---|---|---|
| 공고번호 | 서울특별시 공고 제2026-1440호 | 서울특별시공고 제2026-1552호 |
| 담당부서 | 서울시 **주택정책과** | 서울시 **주택정책과** |
| 등록일 | 2026-04-30 | 2026-05-18 |
| `nttNo` | **457234** | **458161** |
| 상세 URL | `https://www.seoul.go.kr/news/news_notice.do?bbsNo=277&nttNo=457234` | `…&nttNo=458161` |

> ⚠️ 앞 과업 대장은 소관기관을 **청년주거과**로 적었다. `seoul.go.kr` 고시·공고의
> 담당부서 표기는 **주택정책과**다(⑥ 02-2133-7704 · ⑧ 02-2133-7277). 사실만 적는다.

### 2.3 화면에서 읽은 것 (그대로) · DOM

두 상세 페이지 모두 **게시글 본문 바로 아래**에 같은 문장이 있다:

> 본 저작물은 "공공누리" 제4유형:출처표시+상업적 이용금지+변경금지 조건에 따라 이용 할 수 있습니다.

DOM 은 이렇다 (⑥·⑧ 동일):

```html
<!--// 게시글 본문 -->
<div class="sib-viw-type-basic-button sib-viw-type-basic-button-bottom">
  <div class="ccl-wrap">
    <a href="https://www.kogl.or.kr/info/licenseType4.do"
       title="제4유형 공공누리 유형안내 사이트로 이동(새창)" target="_blank" rel="license">
      <img src="https://seoulboard.seoul.go.kr/humanframe/front/assets/seoul-common/assets/images/lic/lic_4.jpg"
           alt="제4유형:출처표시+상업적 이용금지+변경금지" class="openCcl">
    </a>
    <span>본 저작물은 "공공누리" <a href="https://www.kogl.or.kr/info/licenseType4.do" …>제4유형:출처표시+상업적 이용금지+변경금지</a> 조건에 따라 이용 할 수 있습니다.</span>
  </div>
```

**마크 이미지(`lic_4.jpg`) · `rel="license"` · KOGL 유형안내로의 링크**가 모두 있다.
서술 문장뿐인 게 아니라 **부착된 마크**다.

### 2.4 ★ 이게 템플릿 상투구가 아니라는 대조 관측

「모든 페이지 밑에 붙는 문구 아닌가」를 배제해야 판정이 성립한다. 같은 `seoul.go.kr` 에서:

| 페이지 | `lic_*.jpg` | 판정 |
|---|---|---|
| 고시·공고 상세 ⑥ (`nttNo=457234`) | **`lic_4.jpg`** | 부착 |
| 고시·공고 상세 ⑧ (`nttNo=458161`) | **`lic_4.jpg`** | 부착 |
| 고시·공고 상세 (다른 건, `nttNo=463813` 청년 부동산 중개보수 지원 공고) | `lic_4.jpg` | 부착 |
| 고시·공고 상세 (다른 건, `nttNo=463927` 전통사찰보존구역 열람공고) | `lic_4.jpg` | 부착 |
| **보도자료 상세** (`news_report.do?bbsNo=158&nttNo=463952`) | **없음** | **미부착** |
| 고시·공고 **목록** 페이지 | 없음 | (상세에만 붙는다) |
| 저작권 정책 페이지 (`helper/copyright.do`) | (문장) 제4유형 | 부착 |

→ **같은 사이트에서 붙는 게시판과 붙지 않는 게시판이 갈린다.**
전역 푸터 상투구가 아니라 **고시·공고 게시물에 부착된 표시**다.

한편 **서울주거포털**(`housing.seoul.go.kr`) 게시글에는 CMS 템플릿에
`<!-- 공공누리 --> … <!-- 공공누리 끝-->` 슬롯이 있으나 **비어서 렌더된다**
(12667 · 12668 · 12561 전부 동일). 이 포털에서 유형을 읽을 수 없었던 이유가 이것이다.
**슬롯이 비었다는 것은 「유형이 없다」의 근거가 되지 못한다** — 이 포털에서 채워진 예를
하나도 보지 못했으므로 슬롯이 동작하는지 자체를 알 수 없다.

### 2.5 ★★ 마크가 붙은 그 게시물의 첨부파일이 **우리가 가진 바로 그 파일**이다

「마크는 웹페이지에 붙었을 뿐 우리가 받은 PDF 와는 다른 저작물 아닌가」를 배제하기 위해
`seoul.go.kr` 첨부를 다시 받아 **바이트·해시로 대조**했다.


|---|---|---|---|
| ⑥ 크기 | **413,817**바이트 | 413,817바이트 | ✅ |
| ⑥ sha256 | `80de4494292b3d7526749bddf12509843d4ffd9a8ae2d944a32cb33c008e0f1d` | `80de4494292b3d75…` | ✅ |

→ **다른 포털을 거쳐 받았을 뿐 같은 파일이다.** 제4유형 마크가 붙은 게시물의 첨부다.

> ★ 다만 **마크의 문언은 「본 저작물은」이고, 그것이 첨부파일까지 가리키는지 명시하지 않는다.**
> 게시물의 일부라고 읽는 것이 자연스럽지만 **그것은 해석이며 이 문서에서 하지 않는다.**

### 2.6 서울시 저작권 정책 원문 — 「부착되지 않은 자료」 조항

https://www.seoul.go.kr/helper/copyright.do (수정일 2026-02-06, 2026-08-14 원문확인)

> 저작권법 제24조의2(공공저작물의 자유이용)에 따라 서울특별시에서 저작재산권의 전부를
> 보유하고 있거나 자유이용허락표시에 대한 권리자의 동의를 받은 경우는 "공공저작물
> 자유이용허락표시기준(공공누리, KOGL)"을 부착하여 별도의 이용허락 없이 자유이용이 가능합니다.

> 공공누리 제1유형부터 제4유형은 출처(발행연도, 해당 공공기관명과 홈페이지 URL, 저작물
> 작성자의 성명이 표시된 경우에는 그 성명도 포함)를 반드시 표시하여야 합니다.
>
> (예시)
> 본 저작물은 서울특별시에서 'OOOO년' 작성하여 공공누리 제O유형으로 개방한
> '저작물명(작성자:OOOO)'을 이용하였으며, 해당 저작물은 서울특별시 누리집(홈페이지)
> 'http://seoul.go.kr'에서 무료로 다운받으실 수 있습니다.

> **공공누리가 부착되지 않은 자료들**을 이용하고자 할 경우에는 공공저작물 관리책임관 및
> 실무담당자와 사전에 협의하여 이용해 주시기 바랍니다.
>
> 공공저작물 관리책임관 : 정보시스템과 임승철 과장
> 공공저작물 실무담당자 : 정보시스템과 박소영 주무관(02-2133-2963)

같은 페이지가 제0~4유형과 AI유형의 이용허락 범위를 표로 정의한다. 제4유형:

> [제4유형: 출처명시+상업적 이용금지 +변경금지]
> 공공저작물의 출처를 명시하여 이용할 수 있으나, 상업적 목적으로 이용하거나
> 2차적저작물 작성 등 변경하여 이용하는 것은 금지된다.

→ **사전 협의 조항은 「부착되지 않은 자료」에 걸린다.** ⑥⑧ 은 부착되어 있다.

### 3.1 ⚠️ 기록해 두는 사실 — 국토교통부 **본부** 정책은 다르다

> 자유이용의 경우에는 반드시 저작물의 출처를 구체적으로 표시하여야 합니다.

> **공공누리가 부착되지 않은 자료들**을 사용하고자 할 경우에는 해당 컨텐츠를 제공하는 담당부서의
> 담당자와 사전에 협의한 이후에 이용하여 주시기 바랍니다.

- 이 정책의 적용 범위는 문언상 **「국토교통부 홈페이지」(`www.molit.go.kr`)** 다
- 우리 ①③④⑨ 는 **`nhuf.molit.go.kr`(주택도시기금포털)** 에서 받았고, 그 포털은

## 5. 확인하지 않은 것

1. **첨부 PDF 자체에 마크가 붙어 있는지 이번에 다시 열어 확인하지 않았다.** 앞 과업이
   「PDF 내부 마크 이미지 0건」을 확인한 것을 그대로 둔다. 이번 판정의 근거는
   **게시물에 부착된 마크**다
2. **제4유형 마크가 첨부파일까지 가리키는지 서울시에 확인하지 않았다** (2.5 각주).
   문언은 「본 저작물은」이고 대상 범위를 명시하지 않는다
3. **서울주거포털(`housing.seoul.go.kr`)의 공공누리 슬롯이 동작하는지 확인하지 못했다.**
   채워진 예를 하나도 찾지 못했다 — 「비어 있다」의 뜻을 확정할 수 없다
4. **`seoul.go.kr` 고시·공고 게시판이 언제나 제4유형인지 전수 확인하지 않았다.**
   4건(⑥⑧ + 2건)을 봤고 전부 제4유형이었다
5. **복지로 ⑤ 는 유형을 특정하지 못했다** (4절). 정보공개청구·고객센터 문의를 하지 않았다
6. **`www.molit.go.kr` 과 `nhuf.molit.go.kr` 중 어느 저작권정책이 기금포털 자료에 걸리는지
   판단하지 않았다** (3.1)
7. **소관부서 표기 불일치를 해소하지 않았다** — 대장은 청년주거과, `seoul.go.kr` 은 주택정책과 (2.2)
8. **제4유형의 조건(상업적 이용금지·변경금지) 아래에서 우리 파이프라인이 무엇을 할 수 있는지
   판단하지 않았다.** 유형 확인이 이 문서의 범위다
