# 프론트엔드 시각 QA 기록 (W6)

대상: `frontend/{index.html, styles.css, app.js}`
방법: Playwright(Chromium) 실제 구동 → 1440×900 데스크톱 / 390×844 모바일 전체 페이지 캡처 →
PNG 육안 확인 → 수정 → 재캡처. 총 5회 반복.

재현:
```
cd frontend/qa
python qa_shot.py final          # 백엔드 기동 상태. 기본 http://127.0.0.1:8000 (scripts/dev.bat)
                                 # 다른 포트면 QA_URL 로 준다
python qa_offline.py             # file:// 로 열어 /api/* 전면 차단 → 로컬 판정 경로 검증
QA_URL=http://127.0.0.1:8000/ python qa_offline.py   # 같은 오리진에서 서빙하되 /api/* 만 차단
```

`qa_shot.py` 는 보고서를, 둘 다 스크린샷을 이 디렉터리에 떨군다. **둘 다 `.gitignore` 대상이다** —
커밋된 실행 산출물은 코드가 바뀌면 조용히 거짓이 된다.

## 최종 검증 결과 (W6 당시)

- **콘솔 에러 0** — 데스크톱/모바일, 온보딩·대시보드·채팅 전 구간.
- **가로 스크롤 없음** — 데스크톱 1440/1440, 모바일 390/390.
- **대비** — 렌더된 모든 텍스트가 AA 통과. (그라디언트 배경 카드는 스크립트가 측정 불가로 제외하며, 수동 계산 결과 요약 카드 본문 15.5:1 / 메타 5.0:1로 통과)
- **흐름** — 폼 입력 → 진단 → 대시보드(시나리오 4 · 정책 9~10 · 리스크) → 채팅 1턴/2턴 모두 정상. 전송 버튼 busy 중 비활성, 완료 후 복구.
- **오프라인 폴백** — `/api/*` 전면 차단 시 "데모 모드 · 내장 엔진"으로 전환, 지역 9개·시나리오 4개·정책 9개·리스크 41 정상 렌더, 템플릿 채팅 응답 동작.

## 남은 리스크

- 오프라인 시 부팅 프로브(health·regions) 2건이 브라우저 네트워크 레벨 로그를 남깁니다.
  앱은 모두 처리하며, 백엔드 부재를 탐지하려면 요청은 불가피합니다. 앱 예외는 0건입니다.
- 채팅 모드 칩이 실행마다 "LLM 라이브"/"결정론적 템플릿"으로 갈립니다. 백엔드가 반환한
  `mode` 값을 그대로 반영한 것으로, OpenAI 호출 실패 시 폴백이 작동한 결과입니다(프론트 결함 아님).
- `subgrid` 미지원 구형 브라우저는 `@supports`로 기존 flex 레이아웃을 사용합니다(정렬만 완화, 파손 없음).

## 2026-09-01 · 접근성 첫 측정과 폭별 재측정 (T3)

**바로 위 절의 「고치지 않았다」는 더 이상 유효하지 않다.** `.schwabe-name` 잘림은
`-webkit-line-clamp: 2 → 3` 으로 닫혔다. 아래 표가 현재 계약이다.

측정 도구: Playwright(Chromium 151) + axe-core 4.10.2, `wcag2a·2aa·21a·21aa·22aa·best-practice`.
경로: 첫 화면 → 「예시 프로필 채우기」 → 「주거비 진단 시작」 → 대시보드. 각 단계마다 잰다.
**접근성은 이 저장소에서 이때 처음 측정됐다** (그 전까지는 인계 ⑥ 의 공백 항목).

### 측정값 — 전후

| 항목 | 전 | 후 |
|---|---|---|
| axe 위반 (6개 조합 = 2폭 × 3단계) | 3종 · 33노드 | **0** |
| 가로 스크롤 (320~1920px, 30개 폭) | 320px 에서 문서 327px | **전 폭 없음** |
| 텍스트 잘림 (같은 30개 폭) | 375~1280px 에 걸쳐 6개 폭 | **375px 이상 없음** |
| 포커스 표시 없는 탭 정지 | 0 | 0 |
| 24×24 미만 조작 대상 (WCAG 2.2 2.5.8) | `a.brand` 92×15 (390px) | **0** |
| 콘솔 오류 | 0 | 0 |

### axe 가 잡은 것과 원인

| 위반 | 원인 |
|---|---|
| `color-contrast` serious ×31 — 3.62:1 | `.policy[data-status="ineligible"] { opacity: .72 }` 가 카드 전체를 배경 쪽으로 합성했다. `:root` 주석이 보장한다고 적어 둔 ink 램프의 AA 가 opacity 아래에서는 성립하지 않는다 |
| `aria-prohibited-attr` serious ×1 | `#connBadge` 는 role 없는 `<span>` 이라 `aria-label` 을 가질 수 없다. ≤620px 에서 `#connText` 가 `display: none` 이어서 연결 상태가 **색 점 하나로만** 전달됐다 |
| `heading-order` moderate ×1 | `#gradeBody` 가 `h2` 다음에 `h4` 를 냈다 |

### axe 가 못 잡고 손으로 재서 나온 것

- **상단바가 제품 이름을 지운다.** `.topbar-actions` 는 nowrap 이라 줄지 않고 부족분을
  전부 `.brand`(min-width:0)가 먹는다. 잰 브랜드 폭 — 820px:160 · 800px:157 · 768px:127 ·
  700px:63 · **640px:7**. 접힘 임계가 620px 이라 **621~810px 대역에서 이름이 사라진다.**
- **`@media (max-width: 400px)` 의 `.btn-ghost` 축소는 한 번도 적용된 적이 없다.**
  기반 `.btn-ghost` 규칙이 특이도는 같고 순서가 뒤라 이긴다. 측정: 375px 에서
  `#btnSample` 이 padding 13px / font-size 12.5px, 곧 기반값 그대로였다.
- **`role="radiogroup"` 의 계약이 지켜지지 않는다.** 화살표키 핸들러가 없었고 세 버튼이
  모두 탭 정지였다.
- **폼 오류가 토스트뿐이다.** `aria-invalid` · `aria-describedby` · 칸 옆 문구 모두 없었다.
- **`aria-modal="true"` 대화상자에 Escape 도 포커스 가둠도 없다.** 탭 두 번이면 뒤쪽
  페이지로 빠져나가고, 닫아도 초점이 여는 버튼으로 돌아오지 않았다.
- **건너뛰기 링크가 상단바 뒤로 착지한다.** `scroll-padding-top` 이 없어 `#main` 상단
  66px 가 sticky 상단바에 덮였다 (측정 `obscuredPx = 66`).
- **`.factor-list` 의 `minmax(290px, 1fr)`** 가 320px 뷰포트에서 트랙을 붙들어
  문서 폭을 327px 로 벌렸다 — 그 폭의 유일한 가로 스크롤 원인이다.

## 2026-09-02 · ≤620px 직원 로그인 (T11)

**바로 위 「아직 열려 있는 것」에 있던 「≤620px 에서 직원 로그인 불가」는 닫혔다.**
상담원 확장(F7)은 시민 화면 상단바가 유일한 입구이므로, 칸이 없으면 휴대폰에서
로그인 자체가 불가능했다.

계약: ≤620px 에서 `.session-form` 은 상단바 아래 디스클로저 패널로 내려가고, 바에는
`#btnStaffLogin` 토글만 남는다. 상태는 `aria-expanded` 와 `data-open` 둘로만 둔다 —
JS 는 폭을 재지 않는다. 621px 이상은 종전과 같은 인라인 칸이다.

### 측정 (Playwright Chromium + axe-core 4.10.2, 백엔드 기동 상태)

| 항목 | 전 | 후 |
|---|---|---|
| 320px 에서 실제 로그인 제출 | 칸 없음 → **불가** | `.session-who` = `counselor 상담원` |
| 390px 에서 실제 로그인 제출 | 칸 없음 → **불가** | `.session-who` = `counselor 상담원` |
| 가로 스크롤 320 / 390px | 0 / 0 | **0 / 0** (패널 열린 상태에서도 0) |
| axe 위반 320 / 390px (첫 화면 · 패널 열림) | 0 | **0** |
| 브랜드 이름 폭 320·390·620·621·653·700·768·810·811·1440 | 38·92·92·115·115·115·115·115·115·115 | **동일** |
| `.session` 폭 ≤620px | 82px (제출 버튼만) | **82px** (토글만) — 상단바 폭 예산 불변 |
| 621·700·810·1440px 인라인 로그인 | 됨 | 됨 (`toggleDisplay: none`) |

키보드: 토글 → `#loginUser` 로 초점 이동, Escape 로 접고 초점은 토글로 복귀
(측정 `escFocus = btnStaffLogin`). 바깥 `pointerdown` 으로도 접힌다.

### 이번에 닫지 않은 것
