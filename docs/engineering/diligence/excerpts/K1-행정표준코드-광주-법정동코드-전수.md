## 6. 다음 사람이 같은 길로 다시 오게 — 도달 경로

```
orca tab create --url "https://www.code.go.kr/stdcode/regCodeL.do" --json
```

시/도 선택 상자는 `id=Type1`(name=`sidoCd`), 시/군/구는 `id=Type2`(name=`sggCd`)다.
**시군구 목록은 시도 선택 시 ajax 로 채워지므로** `change` 이벤트를 직접 쏴야 한다:

```js
const s = document.getElementById("Type1");
s.value = "12";
s.dispatchEvent(new Event("change", {bubbles:true}));
// 약 1초 뒤
[...document.getElementById("Type2").options].map(o => o.value + "|" + o.text)
```

단건 조회는 폼(`document.forms["form"]`)에 넣고 사이트 자신의 핸들러를 부른다:

```js
const f = document.forms["form"];
f.regionCd.value = "2920000000";                       // 법정동코드 10자리
[...f.querySelectorAll("input[name=disuseAt]")].forEach(r => r.checked = (r.value === "ALL"));
["chkClsDt","chkCrtDt","chkHigh"].forEach(n => f.querySelector("input[name="+n+"]").checked = true);
func_search("10");
```

- ⚠️ 체크박스에 `dispatchEvent(new Event("click"))` 을 **쏘면 안 된다.** 합성 click 이
  `checked` 를 도로 뒤집어서 조회마다 폐지일 칸이 나왔다 안 나왔다 한다. `checked=true` 만 준다.
- ⚠️ `orca ... --json` 을 파이프로 바로 읽으면 콘솔 코덱에 걸려 한글이 깨진다.
  **파일로 받아 UTF-8 로 파싱**했다 (`FINDINGS-4.md` 3.5 와 같다).
