## 1. 결론

**있다.** `DT_1L9U105` 의 `가계수지항목별` 분류는 **2레벨**이고,
레벨2 에 `04.주거 · 수도 · 광열` 의 **세부 5개 항목이 전부 들어 있다.**
가구원수 7개 구간(전체 평균·1인·2인·3인·4인이상·4인·5인이상) 모두에 대해 값이 공표된다.

기본 조회 화면이 **레벨1 만 선택된 상태로 열리기 때문에** 세부 항목이 보이지 않았던 것이지,
공표되지 않는 것이 아니었다. 2차 실사(R4)가 이 표를 열었을 때 본 206행은
`7 × 29(레벨1)` 였고, 레벨2 를 켜면 `7 × 34` = 241행이 된다.

### ② 「조회설정」 패널을 연다

```js
var w = document.getElementById("iframe_rightMenu").contentDocument
          .getElementById("iframe_centerMenu2").contentWindow;
```

> 열렸는지는 `d.querySelector(".sett_box").style.display` 로 확인한다.

### ③ 가계수지항목별 트리(`#fancytree_2`)의 레벨2 노드를 켠다

```js
var t = w.$.ui.fancytree.getTree("#fancytree_2");
["_57","_58","_59","_60","_61"].forEach(k => t.getNodeByKey(k).setSelected(true));
// _57 실제주거비 / _58 주택유지및수선 / _59 상하수도및폐기물처리

```

> **노드 key(`_57`…)는 이 표의 트리 구축 순서에 따라 붙는다.** 다른 표에서는 다른 번호다.
> 이름으로 다시 찾으려면 `t.visit(n => {...n.title...})` 로 훑어라.
> 화면에서 하는 것과 같은 조작: 가계수지항목별 옆 「펼치기」 → `04.주거 · 수도 · 광열` 을 펼쳐
> 하위 5개 체크박스를 켠다. (드롭다운 `#fancytree_2CheckOption` 의
> 「하위레벨 전체선택」을 써도 같은 결과가 되지만, 그러면 12대 비목 **전부**의 하위가 켜진다.)

### ⑤ 그리드를 읽는다

```js
var d  = document.getElementById("iframe_rightMenu").contentDocument
           .getElementById("iframe_centerMenu2").contentDocument;
var cp = d.getElementById("copyMainTable");   // 행 레이블 (가구원수별 | 가계수지항목별)
```

> **함정 (2차 실사가 이미 적어 둔 것).** 그리드 iframe 의 src(`statHtmlContent.do?...`)를
> 단독 탭으로 열면 `#mainTable` 이 비어 있다. 반드시 부모 프레임을 거쳐 트리를 클릭해야 한다.

> **URL 로는 고정되지 않는다.** 「주소/출처 → URL생성」이 내주는 값은
> `https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1L9U105&conn_path=I2`
> 뿐이고 **항목 선택을 담지 않는다.** 위 ②~④ 를 매번 다시 해야 한다.

항상 17번째 항목이다 — 행 인덱스가 뒤섞이지 않았다는 뜻이다.
