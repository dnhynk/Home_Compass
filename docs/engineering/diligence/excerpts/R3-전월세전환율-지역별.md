- 조회일: 2026-08-13
- 취득 수단: Orca 내장 브라우저. **KOSIS 그리드 iframe 의 `#mainTable` 셀 텍스트를 직접 읽었다.**

## 1. 도달 경로 (재현 가능)

```
# ① KOSIS 통계표 화면. 브라우저는 sso.kosis.kr 왕복을 마치고 돌아온다
orca goto --url "https://kosis.kr/statHtml/statHtml.do?orgId=408&tblId=DT_30404_N0010" --json
#   최종 URL 은 ...statHtml.do?sso=ok&returnurl=... 로 보이지만 document.title 은 「지역별 전월세전환율」이다.
#   → 이 화면이 맞다. 앞 조사의 302 실패는 HTTP 클라이언트가 SSO 왕복을 못 끝냈기 때문이다.
# 좌측 트리(iframe_leftMenu) 렌더링 대기 약 25초

# ② 좌측 트리에서 통계표를 클릭한다 (이것을 해야 그리드가 생성된다)
orca snapshot --json
#   link "지역별 전월세전환율 (월 2011.01~2026.05)"  ← 이번엔 ref=@e118
orca click --element "@e118" --json
# 그리드 로딩 대기 약 30초

# ③ 그리드는 2단 중첩 iframe 안에 있다. #mainTable(데이터) · #mainTableT(머리글)
orca eval --expression '
  var d = document.getElementById("iframe_rightMenu").contentDocument
            .getElementById("iframe_centerMenu2").contentDocument;
  d.getElementById("mainTable") ...' --json
```

> **함정.** `iframe_centerMenu2` 의 src 인
> `https://kosis.kr/statHtml/statHtmlContent.do?orgId=408&tblId=DT_30404_N0010&pub=2&conn_path=Z1&list_id=I1_7_005&vw_cd=MT_ZTITLE&language=ko&dbUser=NSI.&tabYn=Y&itm_id=`
> 을 **단독 탭으로 열면 `#mainTable` 이 비어 있다.** 조회조건 패널만 렌더링된다.
> 반드시 부모 프레임(`statHtml.do`)을 거쳐 트리를 클릭해야 데이터가 채워진다.

## 4. 열 대응의 검증

이 표는 **HTML `<table>` 이므로 셀 인덱스가 그대로 열이다.** PDF 추출기처럼 열이 뒤섞일 여지가 없다.
`#mainTableT`(머리글 2행)와 `#mainTable`(데이터)의 셀 수가 11로 동일한 것을 확인했고,
행 라벨 5칸 + 시점 6칸 = 11 로 맞아떨어진다.

## 5. 확인하지 않은 것

- **`규모별 전월세전환율`**(같은 조사, KOSIS `DT_30404_N0009` 계열, 트리에 있음)은 열지 않았다.
- 2026.06 이후 값은 아직 공표되지 않았다 (수록기간 최신 = 2026.05, 자료갱신일 2026-07-30).
- 한국부동산원 R-ONE 포털(`reb.or.kr`) 경로로는 접근하지 않았다. KOSIS 경로로 충분했다.
