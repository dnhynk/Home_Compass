## 5. 열 대응의 검증 — **산술로 확인했다**

PDF 표는 추출기가 열을 뒤섞을 수 있으므로, **본문 서술의 증감 진술과 산술 대조**했다 (p.101 본문):

```
○지역별로 중위수 기준 RIR을 비교하면, 수도권이 18.4%로 가장 높고, 광역시 등이 15.2%, 도지역이 12.7%로 나타남
 -수도권의 RIR은 18.4%로 전년(20.3%) 대비 1.9%p 하락했으며, 광역시 등은 2023년 15.3%에서 0.1%p 하락한 15.2%임
 -도지역의 RIR은 12.7%로 전년(13.0%) 대비 0.3%p 하락하여 중위수 RIR은 모든 지역에서 전년 대비 하락함
○소득별 중위수 기준 RIR은 소득 상위 가구가 19.4%로 가장 높고, 하위 가구는 18.3%, 중위 가구 16.2% 순임
 -소득 하위 가구의 RIR은 전년(19.8%) 대비 1.5%p 감소했고, 중위 가구도 0.6%p 감소했지만,
  상위 가구는 전년(18.7%) 대비 0.7%p 증가함
○소득별 평균 기준 RIR은 소득 상위 가구 24.1%, 하위 가구 22.1%, 중위 가구 20.2% 순임
```

대조 결과 (마지막 두 열 = 2023, 2024):

## 6. 덧붙여 확인된 것 — 「3배 이상 격차」 서술은 이 데이터에서 재현되지 않는다

`FINDINGS.md` 2절이 남긴 물음의 답이다. 2024년 중위수 기준:

```
일반(전체) 15.8  ·  청년 16.0  ·  소득 하위 18.3  ·  소득 상위 19.4
```

**최대·최소 비는 19.4 / 15.8 ≈ 1.23배다.** 어느 두 모집단을 잡아도 3배가 나오지 않는다.
SPEC Part 0-C 의 「청년 RIR 이 일반 기준과 저소득층 기준 사이에서 3배 이상 벌어진다」는 서술은
**2024년도 주거실태조사에서 근거를 찾을 수 없다.**

## 8. 확인하지 않은 것
